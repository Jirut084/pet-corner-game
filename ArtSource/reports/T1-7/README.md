# T1-7 — ภาพสถานีสำหรับรายงานและสไลด์

จัดทำวันที่ 2 พฤศจิกายน 2026 สำหรับโฟลเดอร์รวมรายงาน T3-6
เปิด index.html เพื่อเลือกภาพ หรือใช้ PNG แยกไฟล์ในสไลด์ได้โดยตรง

## ไฟล์ส่งงาน

- 01_Renders_1080: เรนเดอร์สถานีทั้ง 9 ตัว ขนาด 1080 × 1080 px พื้นหลังเทา มุมกล้อง orthographic แสง และระยะกล้องเดียวกันทุกตัว
- 02_Concepts: ภาพแนวคิด T1-2 แบบ A/B/C พร้อมเครื่องรับสัตว์เดิมสำหรับเทียบรูปทรง แบบที่เลือกคือ A เคาน์เตอร์เตี้ยพร้อมกระดิ่ง
- 03_Source: ไฟล์ .blend ของแนวคิด A/B/C, return_counter, groom_colored, play_colored, rest_colored และสคริปต์ export จาก T1-1
- 04_InGame_BeforeAfter: ภาพจากกล้อง Unity ระหว่าง Play Mode ขนาด 1920 × 1080 px ก่อนและหลังเปลี่ยน prefab
- render_manifest.json: แหล่งโมเดล ขนาด และไฟล์ภาพของแต่ละสถานี

สถานีในชุด: Food, Bath, Groom, Play, Rest, Intake, Return, HoldingTable, EquipmentParcel

## ที่มาของภาพก่อนและหลัง

ภาพก่อนเป็นการสร้างซ้ำจาก prefab ใน Git commit c069fdb ไม่ใช่ภาพเก่าที่ถ่ายเก็บก่อนเริ่มงาน
ภาพหลังใช้ prefab ปัจจุบันจาก branch pasit ถึง commit 235ad21
ทั้งคู่ใช้ฉาก Shop และโค้ดเกมชุดเดียวกันในสำเนาทดสอบ ปลดล็อกสถานีครบ และจัดแถวสถานีเพื่อให้เทียบได้ชัด
ใช้กล้อง overview ตำแหน่งและระยะเดียวกัน โดยไม่มี HUD ในภาพ
การจัดแถวและกล้องมีผลเฉพาะขณะถ่ายภาพในสำเนาทดสอบ ไม่บันทึกกลับฉากโปรเจกต์หลัก
ความแตกต่างที่ต้องดู: Groom สีชมพู, Play สีเขียว, Rest เปลี่ยนกรงเป็นเบาะส้ม และ Return เปลี่ยนเครื่องคิดเงินเป็นเคาน์เตอร์สีเขียว
ภาพถ่ายนี้ใช้ประกอบรายงานภาพ ไม่ใช่หลักฐานว่าทดสอบการเล่นจบวันแล้ว

## แหล่งโมเดลและวิธีเรนเดอร์

Food ใช้ geometry และ material ของ Food.prefab ปัจจุบัน ซึ่งยังใช้ feeding bowl เดิม ส่วน Bath และ Intake ใช้โมเดลเดิมใน Assets/Models
Groom, Play, Rest และ Return ใช้ FBX ใน Assets/Art/Stations
HoldingTable ใช้ geometry ของ prefab ทั้งตัว รวมเบาะที่วางอยู่บนโต๊ะ ส่วน EquipmentParcel ใช้โมเดล Kenney จาก Assets/ThirdParty
FBX ของ Kenney เป็น ASCII ซึ่ง Blender 3.5 อ่านตรงๆ ไม่ได้ จึงอ่าน geometry และสีผ่าน Unity แล้วนำไปเรนเดอร์ใน Blender โดยไม่เปลี่ยนรูปทรง ใช้วิธีเดียวกันกับ Food เพื่อให้ตรงกับ material ที่ prefab ใช้จริง
ไฟล์ต้นฉบับของโมเดลเดิมยังอยู่ในโปรเจกต์ ชุดนี้แนบไฟล์ร่างที่สร้างในงาน T1-2/T1-3 ครบ

สีหลักของงานใหม่: Groom #E673E6, Play #73D973, Rest #FF9940, Return #66B873
สีในภาพเรนเดอร์อาจต่างจากค่าสี material เล็กน้อยตามแสงและเงา

## ใช้ไฟล์ต้นฉบับ

เปิด .blend ด้วย Blender 3.5 หรือเวอร์ชันที่เข้ากันได้
ก่อน export ให้แก้ EXPORT_DIRECTORY ในสำเนา export_fbx.py ให้ชี้ Assets/Art/Stations ของเครื่องที่ใช้งาน
ไฟล์ .blend ที่แนบเป็นสำเนาสำหรับส่งงาน ไม่ได้เพิ่มหรือแก้ไฟล์เกมใน commit
